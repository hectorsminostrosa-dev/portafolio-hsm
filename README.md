# Portafolio - Héctor San Martín

Este archivo ZIP contiene el código fuente completo del portafolio web personal, incluyendo:
- index.html (Estructura optimizada con Tailwind CSS, secciones de Reels, Video Claude, Mailing & Email Marketing, ¿Quién soy?, CV y Contacto).
- Integración de la sección de Mailing con Brevo, segmentación e IA para email blasts.

## Cómo usarlo:
1. Extrae el contenido del archivo ZIP en una carpeta de tu computador.
2. Abre el archivo `index.html` en cualquier navegador web o editor de código (como VS Code).
3. Si deseas incluir tu CV en PDF, puedes colocar un archivo llamado `cv.pdf` en la misma carpeta.
