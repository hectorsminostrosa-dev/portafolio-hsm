# Portafolio Profesional - Héctor San Martín Inostrosa

Proyecto web profesional optimizado para marketing digital y community management desarrollado con Next.js y Tailwind CSS.

## ¿Cómo subirlo a Vercel mediante un archivo ZIP / Carpeta?

1. Descomprime este archivo ZIP en tu computador.
2. Inicia sesión en [Vercel](https://vercel.com/).
3. Haz clic en **"Add New..."** -> **"Project"**.
4. En lugar de conectar un repositorio de GitHub, busca la opción de importar código arrastrando o seleccionando la carpeta descomprimida (o sube el archivo .zip directamente si la interfaz de Vercel lo permite, o bien arrastra la carpeta a tu escritorio y súbela).
5. Vercel detectará automáticamente que es un proyecto de Next.js. Haz clic en **Deploy**.
6. ¡Listo! Tendrás tu portafolio online en segundos.
